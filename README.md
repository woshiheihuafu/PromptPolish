# PromptPolish

在原应用的输入框中优化 Prompt，预览对比后直接替换，省去来回复制粘贴。面向 Codex Desktop、Cursor 等应用的文本输入场景，常驻 macOS 菜单栏。

**适用版本：1.1.2 · macOS 14 及以上 · Apple Silicon（M 系列芯片）**

## 主要功能

- **就地优化**：点击输入框旁的悬浮按钮，或按 **⌘⇧E**。
- **原文对比**：查看并编辑优化结果，支持重新优化、取消和替换。
- **自定义规则**：设置全局优化提示词，或配置最多 5 个独立场景。
- **快速替换**：可选择优化完成后自动写回，始终不会自动发送消息。
- **撤销替换**：从菜单栏恢复上次替换前的内容；已有新编辑时会停止撤销，避免覆盖。

## 下载与安装

1. 前往 [Releases](https://github.com/woshiheihuafu/PromptPolish/releases) 下载已发布的 DMG 或 ZIP 安装包。
2. 打开 DMG，将 **PromptPolish** 拖入「应用程序」；使用 ZIP 时，先解压，再移动应用。
3. 打开 PromptPolish，通过菜单栏图标进入设置。

应用尚未经过 Apple 公证，首次打开可能出现安全提示。确认安装包来自本仓库后，可在「系统设置 → 隐私与安全性」中按系统提示允许打开。

## 首次配置

### 辅助功能权限

在「设置 → 权限与兼容性」中打开系统设置，为 **PromptPolish** 开启辅助功能权限。此权限用于读取和替换你主动触发优化的输入框内容。

### AI 服务

在「设置 → AI 服务」中填写并保存：

| 配置项 | 填写内容 |
| --- | --- |
| API Key | 你的 AI 服务商提供的密钥 |
| Base URL | 服务根地址，例如 `https://api.example.com/v1`，不要附加 `chat/completions` 或 `responses` |
| 模型 ID | 服务商提供的完整模型名称 |
| API 协议 | 按服务商说明选择 Chat Completions 或 Responses |

支持 OpenAI 兼容的文本接口。远程服务地址需使用 HTTPS；本机服务可使用 HTTP。可先点击「测试连接」检查配置，测试成功后仍需点击「保存」。

需要单独配置 API Key，不能直接使用 Codex 或 Cursor 的登录状态。API 调用费用由你选择的服务商收取。

## 日常使用

1. 在原应用的输入框中输入文字，点击悬浮优化按钮，或按 **⌘⇧E**。
2. 在对比窗口查看原文和优化结果；可以编辑结果、重新优化，或取消。
3. 点击「替换原文」或按 **⌘ Return** 写回。成功后预览自动关闭，消息不会被发送。

如需恢复原文，从菜单栏选择「撤销上次替换」。如果你已经继续编辑，工具会停止撤销，保护新内容；请使用此入口，不依赖原应用的 **⌘Z**。

## 自定义优化方式

### 全局提示词与场景

- **全局提示词**：在「设置 → AI 服务 → 优化提示词」中修改并保存。直接点击按钮或使用快捷键时，会使用全局规则。可查看[默认优化规则与自定义说明](docs/optimization-prompt.md)。
- **场景提示词**：在「设置 → 优化场景」中添加名称和独立提示词，最多 5 个。鼠标悬停在优化按钮上时，按钮展开并显示场景列表；点击场景即可开始优化。
- 场景提示词会**替代全局提示词**，不会叠加。重新优化沿用本次选择的场景；未配置场景时，不显示场景列表。

### 快速替换与成功提示

在「设置 → 通用」中：

- 开启「优化完成后快速替换」，从下一次优化起自动写回，无需手动确认。默认关闭；原文或目标输入框发生变化时，会停止自动替换。
- 「替换成功提示时长」可设为 **0–30 秒**，默认 2 秒。设为 **0 秒**可关闭提示，菜单栏中的撤销入口仍可使用。

## 隐私与使用边界

- API Key 保存在 macOS 钥匙串中；服务地址、模型和偏好保存在本机。
- 优化时，当前文本和所选提示词会发送给你配置的 AI 服务。连接测试仅发送固定短文本。
- 不保存 Prompt 历史记录。原文与最近结果仅临时保留在内存中，最多 30 分钟，退出应用后清除。
- 不自动发送消息。原文变化、目标失效或写回结果无法确认时，会停止继续替换并保留结果供你检查。
- 不读取安全输入框。当前主要支持普通文本；富文本格式和内嵌图片暂不保证保留，检测到嵌入对象时会停止替换。
- 不同应用及版本的兼容性可能不同；部分输入框只能预览，无法直接替换。使用中文输入法时，请先确认候选文字，再触发优化。

## 常见问题

**悬浮按钮没有出现？**

先点击可编辑输入框，检查「通用」中的悬浮按钮开关和辅助功能权限。输入框外侧空间不足时，可尝试 **⌘⇧E**。

**提示找不到输入框或无法替换？**

回到原应用，重新点击输入框后再试。也可在「权限与兼容性」中使用「检测当前输入框」检查读取能力，此操作不会发送 API 请求。部分控件不支持可靠写回。

**钥匙串反复要求确认？**

确认弹窗中的应用为 PromptPolish 后，可按需选择「始终允许」。不要将密钥或系统密码发给他人。
